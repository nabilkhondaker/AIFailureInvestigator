# Research notes

Open questions explored by this codebase:

1. How reliably can feature-based models separate mechanically distinct faults under noise?
2. When does anomaly detection correctly flag a held-out fault without forcing a known label?
3. How should confidence and abstention be communicated when signatures overlap?
4. What is the value of frequency-domain and order features relative to time-domain statistics alone?

See also `README_RESEARCH.md` at the repository root.
