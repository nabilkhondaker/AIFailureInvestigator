# Explainability

The investigation engine does not stop at a class label. It produces:

- Boolean evidence flags (high RMS, high 1×, high HF energy, temperature rise, …)
- Ranked alternative hypotheses
- Supporting / opposing evidence items
- Confidence and optional abstention
- Textual recommendations and explicit limitations

Feature importance from tree models and z-score deviations from a healthy reference can further rank contributing measurements.
