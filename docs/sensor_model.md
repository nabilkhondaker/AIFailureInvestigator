# Sensor model

| Sensor | Role |
|--------|------|
| Vibration | Primary diagnostic channel; harmonics, bearing tones, HF energy |
| Temperature | Thermal drift and fault-induced heating |
| Current | Load and friction-related variation |
| Torque | Load and mechanical resistance |
| Tachometer | Instantaneous RPM with jitter |

Sensor faults (bias, dropout, saturation, spikes, drift) can be injected independently of mechanical faults.
