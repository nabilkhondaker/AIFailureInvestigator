# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

If you discover a security issue in this project, please open a private report via the repository's security advisory feature (or contact the maintainer directly if that channel is unavailable).

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediation

We will acknowledge receipt and aim to provide an initial response within a reasonable time. Do not disclose the issue publicly until a fix has been released or the maintainers have confirmed that disclosure is appropriate.

## Scope notes

This project is research software intended for synthetic data and controlled experiments. It is not a certified industrial diagnostic system and should not be used as the sole basis for safety-critical maintenance decisions.
