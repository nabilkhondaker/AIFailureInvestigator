# Data

Synthetic datasets generated by `neural-failure generate-data` or `scripts/generate_dataset.py` are written here.

- `raw/` — reserved for external raw recordings
- `processed/` — intermediate processed artefacts
- `synthetic/` — NPZ splits (`train.npz`, `val.npz`, `test.npz`) plus `metadata.json`

Do not commit large generated datasets; regenerate with the documented seed and configuration.
